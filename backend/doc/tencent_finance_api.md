# 腾讯财经接口文档 (Tencent Finance API)

该文档整理了腾讯财经（Tencent Finance）的板块/股票排行接口及其返回字段的详细定义。

---

## 1. 股票排行榜接口

### 接口信息

- **接口名称**：获取板块股票排行数据
- **接口 URL**：`https://proxy.finance.qq.com/cgi/cgi-bin/rank/hs/getBoardRankList`
- **请求方式**：`GET`
- **描述**：获取沪深京 A 股、创业板或其他板块的实时排行列表（可按最新价、涨跌幅、涨跌比率等进行升序或降序排列）。

### 请求参数 (Query Parameters)

| 参数名       | 类型    | 必选 | 示例值    | 说明                                                                                 |
| :----------- | :------ | :--- | :-------- | :----------------------------------------------------------------------------------- |
| `_appver`    | string  | 是   | `11.17.0` | App 版本号                                                                           |
| `board_code` | string  | 是   | `aStock`  | 板块代码：<br>- `aStock`：代表全 A 股市场<br>- `cyb`：代表创业板（ChiNext）          |
| `sort_type`  | string  | 是   | `price`   | 排序字段，例如：<br>- `price`：最新价<br>- `zdf`：涨跌幅<br>- `priceRatio`：涨跌比率 |
| `direct`     | string  | 是   | `down`    | 排序方向：<br>- `down`：降序<br>- `up`：升序                                         |
| `offset`     | integer | 是   | `0`       | 分页偏移量（从 0 开始）                                                              |
| `count`      | integer | 是   | `20`      | 每页获取的股票数量，最大值200                                                        |

### 示例请求 (创业板获取示例)
获取创业板前 20 条股票，按涨跌比率降序排列：
`https://proxy.finance.qq.com/cgi/cgi-bin/rank/hs/getBoardRankList?_appver=11.17.0&board_code=cyb&sort_type=priceRatio&direct=down&offset=0&count=20`

## 3. 返回字段详解

### 3.1 外层字段

| 字段名 | 类型    | 说明                   |
| :----- | :------ | :--------------------- |
| `code` | integer | 状态码（`0` 表示成功） |
| `msg`  | string  | 状态信息（如 `"ok"`）  |
| `data` | object  | 返回的核心数据包       |

### 3.2 `data` 对象字段

| 字段名      | 类型    | 说明                         |
| :---------- | :------ | :--------------------------- |
| `rank_list` | array   | 股票排行数据列表             |
| `offset`    | integer | 当前请求的分页偏移量         |
| `total`     | integer | 板块内符合条件的所有股票总数 |

### 3.3 `rank_list` 数组元素字段 (股票详情)

| 字段名       | 含义           | 单位 | 示例值         | 说明 / 备注                                                      |
| :----------- | :------------- | :--- | :------------- | :--------------------------------------------------------------- |
| `code`       | 股票代码       | -    | `"sz300001"`   | 带市场前缀的股票代码（如 `sh` 上海, `sz` 深圳, `bj` 北京）       |
| `name`       | 股票名称       | -    | `"特锐德"`     | 股票的中文简称                                                   |
| `zxj`        | 最新价         | 元   | `"22.95"`      | 当前最新交易价格                                                 |
| `zd`         | 涨跌额         | 元   | `"1.50"`       | 相比前一交易日收盘价的涨跌金额                                   |
| `zdf`        | 涨跌幅         | %    | `"6.99"`       | 涨跌幅度百分比                                                   |
| `hsl`        | 换手率         | %    | `"10.04"`      | 当日成交股数与流通总股数的比率                                   |
| `zf`         | 振幅           | %    | `"13.86"`      | 当日最高价与最低价之差对前收盘价的比率                           |
| `volume`     | 成交量         | 手   | `"19369.33"`   | 当日累计成交量（1手 = 100股）                                    |
| `turnover`   | 成交额         | 万元 | `"416344"`     | 当日累计成交总金额                                               |
| `ltsz`       | 流通市值       | 亿元 | `"442.85"`     | 股票在市场上流通部分的市值                                       |
| `zsz`        | 总市值         | 亿元 | `"2356.20"`    | 股票全部发行股份的总市值                                         |
| `pe_ttm`     | 市盈率 TTM     | 倍   | `"862.36"`     | 滚动市盈率（价格 / 最近四个季度的每股收益之和）                  |
| `pn`         | 市净率 PB      | 倍   | `"80.33"`      | 市净率（价格 / 每股净资产，Tencent 内部缩写 Price / Net assets） |
| `lb`         | 量比           | -    | `"1.00"`       | 开盘后平均每分钟 of 成交量与过去5个交易日之比                    |
| `speed`      | 涨速           | %    | `"0.66"`       | 股价短期内的涨幅变化速度                                         |
| `state`      | 股票状态       | -    | `""`           | 停复牌等状态，正常交易时为空字符串                               |
| `stock_type` | 股票类型       | -    | `"GP-A-CYB"`   | 标识板块类型，如 `GP-A-CYB`（A股创业板）                         |
| `zljlr`      | 主力净流入     | 万元 | `"355.19"`     | 主力净买入金额（即 `zllr` - `zllc`）                             |
| `zllr`       | 主力流入       | 万元 | `"414787.81"`  | 主力买入成交总额                                                 |
| `zllc`       | 主力流出       | 万元 | `"414432.63"`  | 主力卖出成交总额                                                 |
| `zllr_d5`    | 5日主力流入    | 万元 | `"1896407.44"` | 近 5 个交易日的主力买入累计总额                                  |
| `zllc_d5`    | 5日主力流出    | 万元 | `"1888430.47"` | 近 5 个交易日的主力卖出累计总额                                  |
| `zdf_d5`     | 5日涨跌幅      | %    | `"40.90"`      | 最近 5 个交易日的累计涨跌幅                                      |
| `zdf_d10`    | 10日涨跌幅     | %    | `"26.55"`      | 最近 10 个交易日的累计涨跌幅                                     |
| `zdf_d20`    | 20日涨跌幅     | %    | `"95.15"`      | 最近 20 个交易日的累计涨跌幅                                     |
| `zdf_d60`    | 60日涨跌幅     | %    | `"2702.88"`    | 最近 60 个交易日的累计涨跌幅                                     |
| `zdf_w52`    | 52周涨跌幅     | %    | `"2702.88"`    | 最近 52 周（约一年）的累计涨跌幅                                 |
| `zdf_y`      | 今年以来涨跌幅 | %    | `"2702.88"`    | 自本年度首个交易日起的累计涨跌幅                                 |

## 4. 全球/全部股指排行接口

### 接口信息

- **接口名称**：获取全球主要股指排行榜数据
- **接口 URL**：`https://proxy.finance.qq.com/ifzqgtimg/appstock/app/rank/indexRankDetail2`
- **请求方式**：`GET`
- **描述**：获取全球各主要证券交易所大盘指数的实时数据，按地区（常用、美洲、欧洲、亚洲、其他）进行分类。

### 请求参数 (Query Parameters)

| 参数名    | 类型   | 必选 | 示例值    | 说明               |
| :-------- | :----- | :--- | :-------- | :----------------- |
| `_appver` | string | 是   | `11.17.0` | App 版本号（必填） |

## 6. 行业排行榜接口

### 接口信息

- **接口名称**：获取行业板块排行榜数据
- **接口 URL**：`https://proxy.finance.qq.com/cgi/cgi-bin/rank/pt/getRank`
- **请求方式**：`GET`
- **描述**：获取行业板块的实时排行列表（可按最新价、涨跌幅等进行升序或降序排列）。

### 请求参数 (Query Parameters)

| 参数名 | 类型 | 必选 | 默认值 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `_appver` | string | 是 | - | `11.17.0` | App 版本号（必填） |
| `board_type` | string | 是 | - | `hy2` | 板块类型，例如：`hy2` 代表二级行业板块 |
| `sort_type` | string | 是 | - | `price` | 排序字段，例如：`price` 代表最新价，`zdf` 代表涨跌幅 |
| `direct` | string | 是 | - | `down` | 排序方向：`down` 降序，`up` 升序 |
| `offset` | integer | 是 | - | `0` | 分页偏移量（从 0 开始） |
| `count` | integer | 是 | - | `20` | 每页获取的行业数量 |
