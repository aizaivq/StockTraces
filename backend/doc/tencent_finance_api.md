# 腾讯财经接口文档 (Tencent Finance API)

该文档整理了腾讯财经（Tencent Finance）的板块/股票排行接口及其返回字段的详细定义。

---

## 1. 股票排行榜接口

### 接口信息

- **接口名称**：获取板块股票排行数据
- **接口 URL**：`https://proxy.finance.qq.com/cgi/cgi-bin/rank/hs/getBoardRankList`
- **请求方式**：`GET`
- **描述**：获取沪深京 A 股、创业板或其他板块的实时排行列表（可按最新价、涨跌幅、涨跌比率等进行升序或降序排列）。

### 请求参数 (Query Parameters)

| 参数名       | 类型    | 必选 | 示例值    | 说明                                                                                 |
| :----------- | :------ | :--- | :-------- | :----------------------------------------------------------------------------------- |
| `_appver`    | string  | 是   | `11.17.0` | App 版本号                                                                           |
| `board_code` | string  | 是   | `aStock`  | 板块代码：<br>- `aStock`：代表全 A 股市场<br>- `cyb`：代表创业板（ChiNext）          |
| `sort_type`  | string  | 是   | `price`   | 排序字段，例如：<br>- `price`：最新价<br>- `zdf`：涨跌幅<br>- `priceRatio`：涨跌比率 |
| `direct`     | string  | 是   | `down`    | 排序方向：<br>- `down`：降序<br>- `up`：升序                                         |
| `offset`     | integer | 是   | `0`       | 分页偏移量（从 0 开始）                                                              |
| `count`      | integer | 是   | `20`      | 每页获取的股票数量，最大值200                                                        |

### 示例请求 (创业板获取示例)
获取创业板前 20 条股票，按涨跌比率降序排列：
`https://proxy.finance.qq.com/cgi/cgi-bin/rank/hs/getBoardRankList?_appver=11.17.0&board_code=cyb&sort_type=priceRatio&direct=down&offset=0&count=20`

## 3. 返回字段详解

### 3.1 外层字段

| 字段名 | 类型    | 说明                   |
| :----- | :------ | :--------------------- |
| `code` | integer | 状态码（`0` 表示成功） |
| `msg`  | string  | 状态信息（如 `"ok"`）  |
| `data` | object  | 返回的核心数据包       |

### 3.2 `data` 对象字段

| 字段名      | 类型    | 说明                         |
| :---------- | :------ | :--------------------------- |
| `rank_list` | array   | 股票排行数据列表             |
| `offset`    | integer | 当前请求的分页偏移量         |
| `total`     | integer | 板块内符合条件的所有股票总数 |

### 3.3 `rank_list` 数组元素字段 (股票详情)

| 字段名       | 含义           | 单位 | 示例值         | 说明 / 备注                                                      |
| :----------- | :------------- | :--- | :------------- | :--------------------------------------------------------------- |
| `code`       | 股票代码       | -    | `"sz300001"`   | 带市场前缀的股票代码（如 `sh` 上海, `sz` 深圳, `bj` 北京）       |
| `name`       | 股票名称       | -    | `"特锐德"`     | 股票的中文简称                                                   |
| `zxj`        | 最新价         | 元   | `"22.95"`      | 当前最新交易价格                                                 |
| `zd`         | 涨跌额         | 元   | `"1.50"`       | 相比前一交易日收盘价的涨跌金额                                   |
| `zdf`        | 涨跌幅         | %    | `"6.99"`       | 涨跌幅度百分比                                                   |
| `hsl`        | 换手率         | %    | `"10.04"`      | 当日成交股数与流通总股数的比率                                   |
| `zf`         | 振幅           | %    | `"13.86"`      | 当日最高价与最低价之差对前收盘价的比率                           |
| `volume`     | 成交量         | 手   | `"19369.33"`   | 当日累计成交量（1手 = 100股）                                    |
| `turnover`   | 成交额         | 万元 | `"416344"`     | 当日累计成交总金额                                               |
| `ltsz`       | 流通市值       | 亿元 | `"442.85"`     | 股票在市场上流通部分的市值                                       |
| `zsz`        | 总市值         | 亿元 | `"2356.20"`    | 股票全部发行股份的总市值                                         |
| `pe_ttm`     | 市盈率 TTM     | 倍   | `"862.36"`     | 滚动市盈率（价格 / 最近四个季度的每股收益之和）                  |
| `pn`         | 市净率 PB      | 倍   | `"80.33"`      | 市净率（价格 / 每股净资产，Tencent 内部缩写 Price / Net assets） |
| `lb`         | 量比           | -    | `"1.00"`       | 开盘后平均每分钟 of 成交量与过去5个交易日之比                    |
| `speed`      | 涨速           | %    | `"0.66"`       | 股价短期内的涨幅变化速度                                         |
| `state`      | 股票状态       | -    | `""`           | 停复牌等状态，正常交易时为空字符串                               |
| `stock_type` | 股票类型       | -    | `"GP-A-CYB"`   | 标识板块类型，如 `GP-A-CYB`（A股创业板）                         |
| `zljlr`      | 主力净流入     | 万元 | `"355.19"`     | 主力净买入金额（即 `zllr` - `zllc`）                             |
| `zllr`       | 主力流入       | 万元 | `"414787.81"`  | 主力买入成交总额                                                 |
| `zllc`       | 主力流出       | 万元 | `"414432.63"`  | 主力卖出成交总额                                                 |
| `zllr_d5`    | 5日主力流入    | 万元 | `"1896407.44"` | 近 5 个交易日的主力买入累计总额                                  |
| `zllc_d5`    | 5日主力流出    | 万元 | `"1888430.47"` | 近 5 个交易日的主力卖出累计总额                                  |
| `zdf_d5`     | 5日涨跌幅      | %    | `"40.90"`      | 最近 5 个交易日的累计涨跌幅                                      |
| `zdf_d10`    | 10日涨跌幅     | %    | `"26.55"`      | 最近 10 个交易日的累计涨跌幅                                     |
| `zdf_d20`    | 20日涨跌幅     | %    | `"95.15"`      | 最近 20 个交易日的累计涨跌幅                                     |
| `zdf_d60`    | 60日涨跌幅     | %    | `"2702.88"`    | 最近 60 个交易日的累计涨跌幅                                     |
| `zdf_w52`    | 52周涨跌幅     | %    | `"2702.88"`    | 最近 52 周（约一年）的累计涨跌幅                                 |
| `zdf_y`      | 今年以来涨跌幅 | %    | `"2702.88"`    | 自本年度首个交易日起的累计涨跌幅                                 |

## 4. 全球/全部股指排行接口

### 接口信息

- **接口名称**：获取全球主要股指排行榜数据
- **接口 URL**：`https://proxy.finance.qq.com/ifzqgtimg/appstock/app/rank/indexRankDetail2`

| :-------- | :----- | :--- | :-------- | :----------------- |
| `_appver` | string | 是   | `11.17.0` | App 版本号（必填） |

## 8. 港股排行榜接口

### 接口信息

- **接口名称**：获取港股股票排行数据 (主板 / 创业板)
- **接口 URL**：`https://stock.gtimg.cn/data/hk_rank.php`
- **请求方式**：`GET`
- **描述**：获取香港证券交易所主板或创业板上市的全部港股股票排行。

### 请求参数 (Query Parameters)

| 参数名 | 类型 | 必选 | 默认值 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `board` | string | 是 | - | `main_all` | 板块代码：<br>- `main_all`：代表港股主板全部股票<br>- `gem_all`：代表港股创业板全部股票<br>- `A_H`：代表港股 A+H 股全部股票 |
| `metric` | string | 是 | - | `change_rate` | 排序指标，例如 `change_rate` 代表按涨跌幅排序 |
| `pageSize` | integer | 是 | - | `20` | 每页返回的股票数量 |
| `reqPage` | integer | 是 | - | `1` | 请求的页码（从 1 开始） |
| `order` | string | 是 | - | `desc` | 排序方向：`desc` 降序，`asc` 升序 |
| `var_name` | string | 是 | - | `list_data` | 返回的 Javascript 变量包名，接口必填 |

### 接口返回格式 (JSON Wrapper)
返回结果为 JS 赋值语句包裹的 JSON 数据，例如：
`list_data={"code":0,"msg":"","data":{"page_data":["..."],"page_count":99,"stock_count":1973,"order":"desc","page":0}}`

### `page_data` 数组元素字段说明 (以 `~` 分隔)

每一行股票记录均由 `~` 分隔，例如：
`00648~京玖康疗(新)~3.55~74.02~1.51~3.55~3.55~8044361.00~25311555.31~2.00~2.04~3.99~2.00~7.51`

具体字段位置及释义如下：

| 位置索引 | 含义 | 对应字段名 | 说明 / 备注 |
| :--- | :--- | :--- | :--- |
| `0` | 股票代码 | `symbol` | 不含市场前缀的五位数字代码（如 `00648`） |
| `1` | 股票名称 | `name` | 中文名称 |
| `2` | 最新价 | `lasttrade` | 港币 (HKD) |
| `3` | 涨跌幅 | `changepercent` | 百分比 (%) |
| `4` | 涨跌额 | `pricechange` | 港币 (HKD) |
| `5` | 买入价 (Bid) | `buy` | 港币 (HKD) |
| `6` | 卖出价 (Ask) | `sell` | 港币 (HKD) |
| `7` | 成交量 | `volume` | 累计成交股数 (股) |
| `8` | 成交额 | `amount` | 累计成交金额 (元 / 港币) |
| `9` | 今开盘 | `open` | 港币 (HKD) |
| `10` | 昨收盘 | `prevclose` | 港币 (HKD) |
| `11` | 最高价 | `high` | 当日最高价 |
| `12` | 最低价 | `low` | 当日最低价 |
| `13` | 换手率 | `hsl` | 换手率百分比 (%) |

## 9. 美股中概股排行榜接口

### 接口信息

- **接口名称**：获取美股中概股排行数据
- **接口 URL**：`https://proxy.finance.qq.com/cgi/cgi-bin/rank/us/getList`
- **请求方式**：`GET`
- **描述**：获取美股中概股（CDR）的实时行情排行数据。

### 请求参数 (Query Parameters)

| 参数名 | 类型 | 必选 | 默认值 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `board_type` | string | 是 | - | `cdr` | 板块类型：<br>- `cdr`：代表中概股<br>- `tec`：代表科技股 |
| `sort_type` | string | 是 | - | `price` | 排序字段，如 `price` (最新价), `zdf` (涨跌幅), `volume` (成交量) |
| `direct` | string | 是 | - | `down` | 排序方向：`down` 降序，`up` 升序 |
| `offset` | integer | 是 | - | `0` | 分页偏移量（从 0 开始） |
| `count` | integer | 是 | - | `20` | 每页获取的股票数量 |
| `_appver` | string | 是 | - | `11.17.0` | App 版本号 |

### 接口返回格式 (JSON)
返回字段与 A 股排行接口（`/rank/hs/getBoardRankList`）基本一致：
- `rank_list` 中的 `code` 带有 `us` 前缀和交易所后缀，例如 `usTSM.N` (台积电 NYSE) 或 `usONC.OQ` (百济神州 NASDAQ)。
- `volume`（成交量）单位为“股”。
- `turnover`（成交额）单位为“美元”。
- `ltsz` 与 `zsz` 分别代表流通市值和总市值，单位为“亿美元”。

## 10. 外汇与金属汇率接口

### 接口信息

- **接口名称**：获取外汇与贵金属实时汇率数据
- **接口 URL**：`https://qt.gtimg.cn/`
- **请求方式**：`GET`
- **描述**：获取全球主流外汇货币对以及黄金、白银等贵金属的实时汇率报价。

### 请求参数 (Query Parameters)

| 参数名 | 类型 | 必选 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `q` | string | 是 | `whEURUSD,whUSDCNY` | 汇率代码列表，以逗号分隔。前缀统一为 `wh` |

### 返回格式 (Plaintext GBK)
接口返回文本格式（GBK编码），通过分号分隔，每条汇率数据格式类似 JS 变量赋值：
`v_whUSDCNY="310~美元人民币~USDCNY~6.7770~0~20260610160429~6.7825~6.7721~6.7773~6.7721~6.7770~6.7770~-0.0055~-0.08~-0.02~-0.03~-0.20~-1.46~-3.00~7.2139~6.7613~2026-06-10";`

按波浪号 `~` 分割后的核心字段索引说明：

| 索引 | 字段名 | 说明 |
| :--- | :--- | :--- |
| `0` | 市场分类 | 例如 `310` 表示外汇/贵金属 |
| `1` | 汇率名称 | 例如 `美元人民币` 或 `欧元美元`（注意响应为 GBK 编码） |
| `2` | 汇率代码 | 例如 `USDCNY` 或 `EURUSD` |
| `3` | 最新价 | 当前汇率最新报价 |
| `6` | 昨收价 | 昨日收盘汇率 |
| `8` | 最高价 | 今日最高汇率 |
| `9` | 最低价 | 今日最低汇率 |
| `10` | 开盘价 | 今日开盘汇率 |
| `12` | 涨跌额 | 相比昨收的绝对涨跌值 |
| `13` | 涨跌幅 | 涨跌百分比 (%) |
| `21` | 日期 | 最新报价日期，如 `2026-06-10` |

## 11. 国际期货接口

### 接口信息

- **接口名称**：获取国际主要期货/大宗商品实时数据
- **接口 URL**：`https://proxy.finance.qq.com/ifzqgtimg/appstock/app/rank/worldCommodities?`
- **请求方式**：`GET`
- **描述**：获取全球外汇期货、贵金属、基本金属、农产品、能源等五大品类的实时行情。

### 请求参数 (Query Parameters)

| 参数名 | 类型 | 必选 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `_appver` | string | 否 | `11.17.0` | 版本号 |

### 接口返回格式 (JSON)
返回 JSON 结构体，`data` 对象下有 5 个分类数组：
- `forex`: 外汇期货 (如 CME 加元、澳元)
- `preciousMetal`: 贵金属 (如 COMEX 黄金、白银，伦敦现货)
- `basicMetal`: 常见工业/基本金属 (如 COMEX 铜，LME 铝、镍)
- `agriculture`: 农副产品/活畜期货 (如 CBOT 黄豆、小麦，CME 瘦肉猪)
- `energy`: 能源期货 (如 WTI 原油、布伦特原油、天然气)

每个元素核心字段说明：

| 字段名 | 类型 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- |
| `img` | string | `http://.../fuGC.png` | 图标地址 |
| `code` | string | `GC` | 合约代码 |
| `qtcode` | string | `fuGC` | 行情通道代码 |
| `name` | string | `COMEX黄金` | 期货名称 |
| `zxj` | string | `4191.800` | 最新价 |
| `zde` | string | `-94.600` | 涨跌额 |
| `zdf` | string | `-2.21` | 涨跌幅 (%) |
| `location` | string | `纽约COMEX` | 交易场所名称 |
| `state` | string | `open` | 交易状态 (`open` 或 `close`) |
| `stocktype` | string | `FU_CMXM` | 合约类型 |
