# 本地后端 API 接口文档 (Local Backend API)

该文档整理了本地后端服务提供的股票相关 API 接口定义。

---

## 1. 获取股票列表接口

### 接口信息

- **接口路径**：`/api/stocks`
- **请求方式**：`GET`
- **基础 URL**：`http://localhost:8080` (本地开发环境)
- **描述**：从本地 PostgreSQL 数据库中检索股票列表，支持分页、关键字搜索以及白名单过滤的安全动态排序。支持 CORS 跨域调用。

### 请求参数 (Query Parameters)

| 参数名    | 类型    | 必选 | 默认值 | 示例值 | 说明                                                                                                                                                                                                                                                                                                         |
| :-------- | :------ | :--- | :----- | :----- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `_appver` | string  | 是   | -      | `11.17.0` | 客户端 App 版本号（接口准入必填参数）                                                                                                                                                                                                                                                                        |
| `limit`   | integer | 否   | `20`   | `10`   | 每页获取的股票数量（最大限制 200，以防内存溢出）                                                                                                                                                                                                                                                             |
| `offset`  | integer | 否   | `0`    | `20`   | 分页偏移量（从 0 开始）                                                                                                                                                                                                                                                                                      |
| `keyword` | string  | 否   | -      | `联讯` | 模糊搜索关键字，支持股票代码（如 `sh688808`）或股票中文简称（如 `联讯仪器`）的模糊匹配（不区分大小写）                                                                                                                                                                                                       |
| `board`   | string  | 否   | -      | `cyb`  | 板块分类过滤器（不区分大小写，不提供则默认查询全部）：<br>- `main`：沪深主板<br>- `cyb`：创业板<br>- `kcb`：科创板<br>- `bj`：北京证券交易所（北交所） |
| `sort_by` | string  | 否   | `code` | `zdf`  | 排序字段，只允许白名单中的列：<br>- `code` (代码)<br>- `name` (名称)<br>- `zxj` (最新价)<br>- `zd` (涨跌额)<br>- `zdf` (涨跌幅)<br>- `hsl` (换手率)<br>- `zf` (振幅)<br>- `volume` (成交量)<br>- `turnover` (成交额)<br>- `ltsz` (流通市值)<br>- `zsz` (总市值)<br>- `pe_ttm` (市盈率)<br>- `pn` (市净率) 等 |
| `order`   | string  | 否   | `asc`  | `desc` | 排序方向：<br>- `asc`：升序<br>- `desc`：降序                                                                                                                                                                                                                                                                |

## 2. 获取A股数据统计接口

### 接口信息

- **接口路径**：`/api/stocks/stats`
- **请求方式**：`GET`
- **基础 URL**：`http://localhost:8080`
- **描述**：统计当前本地 PostgreSQL 数据库中所有 A 股的数据，包含总股数、上涨数、下跌数、平盘数、涨停数及跌停数。数据既会分市场（沪、深、京）统计，也提供全市场的汇总（`summary`）统计。支持 CORS 跨域调用。

### 请求参数 (Query Parameters)

| 参数名 | 类型 | 必选 | 默认值 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `_appver` | string | 是 | - | `11.17.0` | 客户端 App 版本号（接口准入必填参数） |

### 返回格式

### 返回字段说明

#### 外层字段
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `code` | integer | 状态码（`0` 表示成功） |
| `msg` | string | 状态信息（如 `"ok"`） |
| `data` | object | 返回的核心数据包 |

#### `data` 内部对象字段（`sh_main`、`sh_kcb`、`sz_main`、`sz_cyb`、`bj`、`summary`）
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `total` | integer | 该市场/全市场的股票总数 |
| `rise` | integer | 上涨股票数量 (`zdf > 0`) |
| `fall` | integer | 下跌股票数量 (`zdf < 0`) |
| `flat` | integer | 平盘股票数量 (`zdf = 0`) |
| `limit_up` | integer | 涨停股票数量（根据各自板块政策计算：主板 10%，科创板/创业板 20%，京市 30%，ST 股 5%） |
| `limit_down` | integer | 跌停股票数量（根据各自板块政策计算：主板 -10%，科创板/创业板 -20%，京市 -30%，ST 股 -5%） |

## 3. 获取全球主要股指排行榜接口

### 接口信息

- **接口路径**：`/api/indices`
- **请求方式**：`GET`
- **基础 URL**：`http://localhost:8080` (本地开发环境)
- **描述**：获取全球各主要证券交易所大盘指数的实时数据，按地区（常用、美洲、欧洲、亚洲、其他）进行分类。本接口作为代理，直接请求腾讯财经全球主要股指接口并返回数据。支持 CORS 跨域调用。

### 请求参数 (Query Parameters)

| :--- | :--- | :--- | :--- | :--- | :--- |

### 返回字段说明

#### 外层字段

| 字段名 | 类型 | 说明 |

## 4. 获取行业板块排行榜接口

### 接口信息

- **接口路径**：`/api/industries`
- **请求方式**：`GET`
- **基础 URL**：`http://localhost:8080` (本地开发环境)
- **描述**：获取行业板块的实时排行列表（可按最新价、涨跌幅等进行升序或降序排列）。本接口作为代理，直接请求腾讯财经行业板块排行接口并返回数据。支持 CORS 跨域调用。

### 请求参数 (Query Parameters)

| 参数名 | 类型 | 必选 | 默认值 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `_appver` | string | 是 | - | `11.17.0` | 客户端 App 版本号（接口准入必填参数） |
| `board_type` | string | 是 | - | `hy2` | 板块类型，例如：`hy2` 代表二级行业板块 |
| `sort_type` | string | 是 | - | `price` | 排序字段，例如：`price` 代表最新价，`zdf` 代表涨跌幅 |
| `direct` | string | 是 | - | `down` | 排序方向：`down` 降序，`up` 升序 |
| `offset` | integer | 是 | - | `0` | 分页偏移量（从 0 开始） |
| `count` | integer | 是 | - | `20` | 每页获取的行业数量 |
